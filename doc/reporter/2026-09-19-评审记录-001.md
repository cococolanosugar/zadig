# 评审记录 001：新旧前端对齐评估（zadig-portal-next）

- **日期**：2026-09-19
- **评审对象**：`frontend/`（React 18 + antd 6 + React Router + ProComponents，分支 `feat/zadig-portal-next`）
- **对照基准**：
  1. 线上实例 `http://192.168.31.174:8380`（浏览器实测：工作台/项目/项目详情/系统集成/企业管理/项目工作流/质量中心/运行状态/资源配置 等页面）
  2. `zadig-ee-portal/` 编译产物静态分析（**Vue 2 + Vue Router，v5.0.0**，~112 个懒加载 chunk，工作流仅 v4，含微前端插件系统与 `/mobile` 移动端树）
- **方法**：编译产物路由/菜单逆向 + 线上页面逐页走查 + 新版逐页源码盘点

---

## 一、总体结论

| 维度 | 状态 | 说明 |
|---|---|---|
| 布局与一级导航 | ✅ 高度对齐 | 侧边栏 4 域、底部固定入口、头部工具位均一致（个别按钮为假动作） |
| 路由骨架 | 🟡 约 70% 覆盖 | 大量路由「同 URL 渲染扁平列表」，属占位实现 |
| 功能深度 | 🔴 差距最大 | 仅 9 个页面有真实后端闭环；另有 5 个页面残留「API 失败 → 展示编造数据」模式（与已完成的 SAMPLE_PODS/DEFAULT_SAMPLE_* 清理同类，本次新发现） |

**方向性结论**：旧版工作流只有 v4，新版全面对齐 v4 是正确方向，无需兼容 v2/v3。

## 三、路由缺失清单

### 🔴 整块缺失（旧有 → 新无）

| 旧路由 | 说明 |
|---|---|
| `/mfa-enroll` | MFA 注册；新版登录无 MFA |
| `/v1/installation/signup`、`/v1/installation/version` | 首次安装引导向导 |
| 找回密码 / 验证码流程 / 第三方登录（OAuth、LDAP、飞书/钉钉/企业微信身份） | 新版登录页仅账号密码+验证码，「找回密码」是假链接 |
| `/v1/insight/detail/{overview,build,test,deploy}`、`/v1/insight/config` | 效能洞察 4 个维度详情页与配置页；新版只有单页 |
| `/v1/releasePlan/detail` | 发布计划详情/编排页 |
| **plutus 整个子树** | `project/create`、项目详情、客户管理、客户控制台（info/env/console/version/config）、交付看板、操作日志——新版 `/v1/plutus` 只是一张扁平表 |
| `/v1/directory/detail/:id` | 业务目录详情 |
| `/v1/delivery/artifacts`（制品追踪）、`version/detail/:project_name/:id` | 新版所有 delivery/version 路由渲染同一张 artifacts 表 |
| 项目级 `group`（变量组）及 `group/create` | 新版已有 rbac/integration/secrets，缺变量组 |
| `/v1/system/aiCodeReview` | AI 代码审查**系统级**配置页（新版只有项目级 `scanner/ai-review`） |
| `/mobile` 整棵树 | 移动端（状态/项目/工作流执行/测试）完全没有 |
| `/v1/plugin/:route*` | 微前端插件渲染路由 |
| `/404` 独立页、`/workspace` | 新版通配符渲染「建设中」占位 |
| `/v1/projects/edit/:name`、`/v1/projects/initialize/:name` | 项目编辑与初始化 |

### 🟡 路由存在但渲染占位/同页复用

| 区域 | 差距 |
|---|---|
| 项目向导 | 旧版支持 **k8s / helm / host / pm / app 五种类型**多步向导；新版仅 `k8s` 一种，且 4 步中后 3 步为纯演示 |
| 环境子树 | 旧版有 `envs/production/*`（生产环境）、`envs/sae/*`（SAE 应用+变更单 changeOrder）、`envs/externalConfig`（配置托管）、`envs/detail/:env_name/envConfig`（环境配置）、`envs/resourceDetail`、`envs/podDetail`；新版仅 `envs/:envName(/k8s\|helm\|pm/:service)` 与 `log` |
| 测试 | `test/function/:test_name`、`add/function`、`detail/function/...`——新版全部渲染同一扁平列表 |
| 构建 | `builds/detail/:buildName` 渲染扁平列表，无详情视图 |
| 模板库 | 旧版 7 类模板（含发布计划模板 + 工作流模板 config 页）；新版 6 tab 中 **4 个 tab（Dockerfile/Chart/构建/扫描）从不发请求**，复用 YAML 模板表 |

## 四、功能实现程度（按页面分级）

### ✅ 真实闭环（9 个）

| 页面 | 覆盖能力 |
|---|---|
| Login | RSA 加密登录 + 验证码 + 角色（`/api/v1/login`、`captcha`、`policy/permission`） |
| Projects | 增/删/查（picket + aslan project API） |
| Pipelines | 列表/创建/删除/触发执行（workflow v4 + workflowtask） |
| PipelineExecution | 任务详情读取 |
| Services | 读 + 保存 YAML |
| Environments | 读 + Pod 终端（WebSocket exec）+ 日志流 |
| Settings 六件套 | Clusters / CodeHosts / Registries / Storage / Users / Config，**真实 CRUD，完成度最高** |

### 🟠 有真实 API 但退化为假数据/假成功（6 个）

| 页面 | 真实部分 | 造假部分 |
|---|---|---|
| Sprints | sprint CRUD API | 空/错时回退到编造的示例迭代；保存/删除失败也报成功 |
| Builds | build CRUD API | 「执行」为纯 setTimeout 假成功；编造示例构建；detail 路由无详情 |
| Scanners | scanning API + 触发 | 编造 3 个示例扫描器（含假质量指标与 AI 建议）；KPI 卡硬编码「通过率 100%」 |
| Quality | 测试列表 + 质量统计 | 「新建测试」「执行测试」假；「平均质检耗时 42 秒」硬编码 |
| Integration | 12 类集成各自真实 GET | 保存/测试连接/删除全部为本地 setTimeout 假动作（连 "HTTP 200 OK" 都是假的）；空数据回退到编造的「已连接」条目 |
| Plutus / Delivery / Enterprise | 各有真实 GET | 新建/控制台/流向图/更新 License 均为假动作 |

### ❌ 纯占位（无后端）

- **Directory**：零 API，新建业务域/拓扑图均为假
- **ReleasePlan**：零 API，新建/详情编排均假，状态列硬编码「进行中」
- **Statistics**：全部指标与图表硬编码（1280 条流水线、342 镜像等），无任何 API
- **Insights**：KPI + 3 张图表硬编码，7d/30d/90d 切换不生效
- **Profile**：MCP token 写死为 `zadig_mcp_sec_live_9f83a812b10927c3`，「重新生成」「更新密码」均假

### ⚠️ 关键功能断点（界面在，但不通）

1. **DAG 编排画布保存不持久化**——`workflowApi.updateWorkflow`（PUT）已封装但从未被调用，画布 onSave 仅改本地 state
2. **任务日志流未接入**——旧版有 `/api/aslan/logs/sse/v4/workflow/*` SSE 接口，新版控制台标「暂未接入日志流」
3. **新建服务只改本地 state**，不调 API
4. **副本伸缩**为假成功；**环境创建**（`envs/create`）渲染的是列表页，无向导
5. **Dashboard「添加卡片」**无持久化

## 五、建议优先级

| 级别 | 内容 |
|---|---|
| **P0 交付闭环**（不做则不可用） | DAG 保存持久化 → 任务日志流接入（SSE）→ 构建执行真实化 → 环境创建向导 → 项目向导后 3 步真实化 |
| **P1 核心页面真实化** | 移除 Sprints/Builds/Scanners/Quality/Integration 的假数据回退与假成功（与已完成的假数据清理同类）；发布计划（`/api/aslan/release_plan/v1/*`）+ 制品追踪（`/api/aslan/delivery/*`） |
| **P2 数据视图** | Statistics/Insights 接 `/api/aslan/stat/*`；补效能洞察 4 个维度详情页 |
| **P3 路由面补齐** | 测试详情/函数测试、生产环境与 SAE、客户交付子树、模板库 4 个未接 tab、MCP/Profile 真实化 |
| **P4 企业特性** | 登录辅助流程（找回密码/第三方登录/MFA）、移动端、微前端插件、侧边栏自定义 |
