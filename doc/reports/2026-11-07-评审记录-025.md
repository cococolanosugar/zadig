## 1. 本轮审查与发现

本轮聚焦 **工作流 V4 执行引擎与任务调试 (Pipelines & WorkflowDAG)**，Cursor 独立审计并由主控复核确认以下核心缺陷：
1. **R2-A1【P0 缺陷】人工审批面板因状态门控过窄而不展示**：
   - 目标位置：`Execution.tsx:610`；
   - 根因：审批卡片门控判断仅认 `pendingApproval && task?.status === 'waiting'`，但后端真实审批态为 `wait_for_approval`（`config.StatusWaitingApprove`），导致真实审批场景下同意/驳回卡片永远不出现，阻断审批流程。
2. **R2-A2 & R2-A3【P1 缺陷】测试产物仅列表无下载闭环、构建产物 API 缺失**：
   - 测试产物弹窗仅渲染文件名列表，无点击下载；
   - 后端路由 `pkg/microservice/aslan/core/workflow/handler/router.go:150-151` 提供的 `GET /workflow/:workflowName/taskId/:taskId/job/:jobName` 与 `/build` 未在前端 API 封装与消费。
3. **R2-A4【P1 缺陷】JUnit 详情与工作空间产物加载静默失败**：
   - `loadJunitReport` 与 `loadWorkspaceFiles` 在 catch 分支静默清空数据，未给予用户反馈。
4. **R2-A5【P1 缺陷】失败任务「重试」缺少二次确认**：
   - 重试按钮直接触发异步请求，缺少 `Popconfirm` 二次确认。
5. **R2-A6【P2 债务】`setWorkflowBreakpoint` 重复残缺代码**：
   - 缺少 `operation` query 参数，属于历史未引用的重复残缺定义。
6. **R2-A8 & R2-A9【P2 体验】触发后跳转脱离项目深链与错误统一兜底**：
   - 触发启动后跳转至全局路径丢失项目上下文；错误捕获仅认响应体 `message` 缺乏通用错误兜底。

## 2. 修复实施核验

主控对 ZCode 提交的代码执行逐项核验：
* **`task.status` 审批状态门控修复 (R2-A1)**：
  - 更新 `WorkflowTaskExecution['status']` 类型定义，加入 `'wait_for_approval' | 'pause' | 'timeout'`；
  - `Execution.tsx` 门控调整为：`pendingApproval && (task?.status === 'wait_for_approval' || task?.status === 'waiting' || task?.status === 'running')`，完美对齐后端审批生命周期。
* **产物下载双接口封装与 UI 完整接线 (R2-A2 / R2-A3)**：
  - 在 `api/workflow.ts` 封装 `downloadArtifactFile` 与 `downloadBuildJobArtifactFile`（指定 `responseType: 'blob'`）；
  - 在 `Execution.tsx` 测试产物列表中为每个文件增加「下载」按钮，点击创建 Blob 链接触发浏览器下载；
  - 在 Job 控制台日志工具栏为构建类型 Job（`selectedJobInfo?.type?.includes('build')`）增加「构建产物」下载按钮。
* **JUnit 与产物错误反馈补齐 (R2-A4)**：
  - 在 `loadJunitReport` 与 `loadWorkspaceFiles` 捕获异常时调用 `feedback.message.error`，彻底杜绝静默失败。
* **任务重试增加二次确认 (R2-A5)**：
  - 为「重试失败任务」按钮包裹 `Popconfirm`（"确定从失败节点重新重试该任务吗？"）。
* **清理残缺死代码 (R2-A6)**：
  - 移除 `api/workflow.ts` 中重复的 `setWorkflowBreakpoint`，保留标准的 `setWorkflowTaskBreakpoint`。
* **项目深链与错误兜底 (R2-A8 / R2-A9)**：
  - `WorkflowTriggerModal.tsx` 触发后优先跳转 `/projects/detail/${projectName}/pipelines/custom/${workflowName}/task/${taskId}` 深链；
  - 错误捕获补齐 `err.message` 兜底。
