## 2. 深度审计发现的链路缺陷与对账结果

### 缺陷 LOOP8-A1：Kubernetes 集群断开/重连状态机缺失与物理删除误触风险
- **后端源码真理源**：
  `pkg/microservice/aslan/core/multicluster/handler/router.go:50-51`：
  ```go
  Cluster.PUT("/:id/disconnect", DisconnectCluster)
  Cluster.PUT("/:id/reconnect", ReconnectCluster)
  Cluster.GET("/:id/deletion", GetDeletionInfo)
  Cluster.DELETE("/:id", DeleteCluster)
  ```
  `pkg/microservice/aslan/core/multicluster/service/clusters.go:420`：
  ```go
  type ClusterDeletionInfo struct {
      Deletable bool       `json:"deletable"`
      EnvInUse  []*EnvInfo `json:"env_in_use,omitempty"`
  }
  ```
- **前端现状缺陷**：
  1. `frontend/src/api/settings.ts` 未声明 `disconnectCluster`、`reconnectCluster` 与 `getClusterDeletionInfo`；
  2. `frontend/src/pages/Settings/Clusters/index.tsx` 操作列仅有一个按钮名为「断开连接」，但底层触发的是 `handleDelete(record.id)`（直接发送 HTTP `DELETE /api/aslan/cluster/clusters/:id`），将临时断开变成了不可逆的物理删除！
  3. 当集群处于 `disconnected` 离线状态时，没有提供「重新连接」入口；
  4. 删除集群时未调用 `GET /api/aslan/cluster/clusters/:id/deletion` 预检环境依赖，若被环境使用直接抛出后端异常，未给用户友好指引。

---

### 缺陷 LOOP8-A2：Helm Chart 仓库索引清单检索（`ListCharts`）与抽屉展示缺失
- **后端源码真理源**：
  `pkg/microservice/aslan/core/system/handler/router.go:180`：
  ```go
  integration.GET("/:name/index", ListCharts)
  ```
  `pkg/microservice/aslan/core/system/service/helm.go:88`：
  ```go
  type IndexFileResp struct {
      Entries map[string][]*ChartVersion `json:"entries"`
  }
  type ChartVersion struct {
      ChartName string `json:"chartName"`
      Version   string `json:"version"`
  }
  ```
- **前端现状缺陷**：
  1. `frontend/src/api/settings.ts` 缺失 `getHelmCharts(repoName: string)` 接口；
  2. `frontend/src/pages/Settings/ChartRepos/index.tsx` 仅支持「添加」和「删除」，用户无法在 UI 上查看该仓库已同步解析出的 Helm Charts 及其版本清单。

---

### 缺陷 LOOP8-A3：镜像仓库引用环境关联安全预检（`GetRegistryReferences`）未落地
- **后端源码真理源**：
  `pkg/microservice/aslan/core/system/handler/registry.go:78` 与 `service/registry.go:120`：
  ```go
  type RegistryReferencesResp struct {
      References []*RegistryReference `json:"references"`
  }
  type RegistryReference struct {
      ProjectName  string                  `json:"project_name"`
      ProjectAlias string                  `json:"project_alias"`
      Envs         []*RegistryReferenceEnv `json:"envs"`
  }
  ```
  路由：`GET /api/aslan/system/registry/namespaces/:id/reference`。
- **前端现状缺陷**：
  1. `frontend/src/api/settings.ts` 缺失 `getRegistryReferences(id: string)` 接口；
  2. `frontend/src/pages/Settings/Registries/index.tsx` 在用户点击「删除」时直接调用 `DELETE`，若该镜像仓库正被某项目的环境使用，会导致后端拦截并抛错，未在前端做关联引用拦截提示。

## 3. 修复任务规划书（分发给 Cursor Agent）

1. **任务 1 (LOOP8-A1)：K8s 集群断开/重连/删除安全状态机完整落地**
   - 在 `frontend/src/api/settings.ts` 补充：
     - `disconnectCluster(id: string): Promise<void>` -> `PUT /api/aslan/cluster/clusters/${id}/disconnect`
     - `reconnectCluster(id: string): Promise<void>` -> `PUT /api/aslan/cluster/clusters/${id}/reconnect`
     - `getClusterDeletionInfo(id: string): Promise<{ deletable: boolean; env_in_use?: Array<{ name: string; display_name: string; project_name: string; production: boolean }> }>` -> `GET /api/aslan/cluster/clusters/${id}/deletion`
   - 在 `frontend/src/pages/Settings/Clusters/index.tsx`：
     - 区分「断开连接」（仅非 local 且在线集群，调用 `disconnectCluster`）与「重新连接」（仅 `record.status === 'disconnected'` 或 `record.disconnected`，调用 `reconnectCluster`）；
     - 区分独立的「删除集群」按钮，点击时调用 `getClusterDeletionInfo` 校验：若 `deletable === false` 则 Modal 弹窗提示正在使用的环境列表并阻止物理删除；若可删除则允许二次确认删除。

2. **任务 2 (LOOP8-A2)：Helm Chart 仓库 Charts 清单抽屉展示**
   - 在 `frontend/src/api/settings.ts` 增加：
     - `getHelmCharts(repoName: string): Promise<{ entries: Record<string, Array<{ chartName: string; version: string }>> }>` -> `GET /api/aslan/system/helm/${encodeURIComponent(repoName)}/index`
   - 在 `frontend/src/pages/Settings/ChartRepos/index.tsx`：
     - 操作列增加「查看 Charts」按钮；
     - 增加 `Modal` 或 `Drawer` 抽屉，支持根据输入的 Chart 仓库名称拉取索引，以表格或列表形式展示 Chart 名称与版本列表。

3. **任务 3 (LOOP8-A3)：镜像仓库删除前引用环境拦截预检**
   - 在 `frontend/src/api/settings.ts` 增加：
     - `getRegistryReferences(id: string): Promise<{ references: Array<{ project_name: string; project_alias: string; envs: Array<{ name: string; alias: string }> }> }>` -> `GET /api/aslan/system/registry/namespaces/${id}/reference`
   - 在 `frontend/src/pages/Settings/Registries/index.tsx`：
     - 删除前调用 `getRegistryReferences` 检查，若存在引用则弹窗列出占用项目与环境并阻止误删。
