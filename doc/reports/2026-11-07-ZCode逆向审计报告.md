## 1. 审计数据集与方法说明

### 1.1 数据集规模

| 数据集 | 提取方式 | 规模 |
| --- | --- | --- |
| 官方门户 API URL 模板 | Node 正则扫描 `zadig-ee-portal/static/js/*.js`（引号锚定 + `${}` 参数归一化） | **441 条**唯一 URL |
| 官方门户路由声明 | 扫描 `path:"..."` / `redirect:"..."` / `component:` 序列 | **202 条**唯一 path |
| 后端 Gin 路由 | 解析 33 个 `router*.go`（变量名→前缀映射 + 花括号作用域快照，还原嵌套 Group 全路径） | **1324 条**完整路由 |
| 新前端 API URL | 扫描 `frontend/src/**/*.{ts,tsx}` | **373 条**唯一 URL |

### 1.2 网关映射约定（比对基准）

官方门户调用 `/api/aslan/X`，后端 aslan 在 `pkg/microservice/aslan/server/rest/router.go:131-157` 以 `/api/<domain>` 挂载各域 Router，网关层剥离 `aslan` 前缀转发。故比对规则为：门户 `/api/aslan/X` ⇔ 后端 `/api/X`。其余服务挂载点：user/systemconfig → `/api/v1`（`pkg/microservice/user/server/rest/router.go:35`）、picket → `/api/v1/picket`（aslan router.go:182）、plutus_enterprise/plutus_vendor → `/api`。

### 1.3 甄别规则

匹配分三级：`exact`（含 `:param` 与 `${param}` 通配形状互认）→ `prefix`（截断伪影，按"后端延伸/门户延伸"分方向）→ `none`（真实缺口）。所有 `none` 项均经人工二次核验（grep 后端源码 + 官方 Bundle 上下文），剔除了模板字符串参数尾截断等 137 条伪影。

## 5. P2 观察项与信息项

1. **picket 权限聚合层未接入（4 条）**：官方门户工作流/测试/用户聚合查询走 `GET /api/v1/picket/{workflows/all, workflows/testName, testing, users}`（picket 为带 RBAC 过滤的聚合网关，`pkg/microservice/picket/core/filter/handler/router.go`）。新前端直连 aslan 对应接口，功能等价，但**权限过滤语义可能与官方不一致**（picket 会按用户角色裁剪结果），建议至少在工作流列表场景评估接入。
2. **次要 API 缺口（6 条）**：`build/targets`（构建目标选择，前端已有 `build/build/targets` 变体）、`cluster/agent`（Agent 连接信息下载）、`code/codehost/infos`、`service/harbor/project`（Harbor 项目联动）、`service/workloads`（原生工作负载导入）、`project/production/products`（生产项目过滤列表）。
3. **企业版依赖项（非缺陷，共 36 条）**：`/api/plutus/*`（交付中心/客户管理/版本部署，32 条）、`/api/directory/*`、`/api/operation/upload*`、`/api/usage`、`/api/v1/{policies, log/upload, log/download, room/create, ws/room/join}`（策略中心/审计日志传输/协同房间）。本地 `pkg/microservice/plutus_vendor` 与 `plutus_enterprise` 仅实现 health/license/organization（`plutus_vendor/core/handler/router.go:29-38`），业务实现位于闭源企业镜像。前端 `plutus/*`、`directory/*` 路由已用通配承接。
4. **拦截器白名单悬空引用**：官方 Bundle axios 错误拦截器引用 `includes("/api/aslan/services/validateUpdate/")` 作为轮询静默白名单，开源后端无此路由；新前端如需对齐错误静默行为可原样保留该常量，无功能影响。
5. **前端超集路由（informational）**：`/login/password`、`/mfa-enroll`、`/mobile/*` 兼容重定向、`resource/{helmChartRepo,database}`、`template/{scanners,releasePlan}` 等为前端额外补充，官方 Bundle 均有对应 i18n/功能锚点（如 `sidebarMenu.mcp`、`sidebarMenu.security`），方向正确。
