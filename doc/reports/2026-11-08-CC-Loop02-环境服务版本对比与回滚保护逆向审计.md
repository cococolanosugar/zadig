### P0-2 生产环境创建：前端漏 query，后端按 query 鉴权却按 body 落库（授权绕过）

- 前端：`frontend/src/pages/Environments/Wizard.tsx:192-217`

### P0-5 `isHelmChart` 语义错配：Helm 项目环境版本历史/回滚恒为空

- 前端：
  - `Environments/index.tsx:195-200` `isHelmEnv` = 项目/环境是否为 Helm 架构；

  - `Environments/ServiceDetail.tsx:732` 又硬编码 `isHelmChart={false}`。
- 后端语义：`common/repository/mongodb/env_svc_version.go:152-183`
  ```go

      query["service.release_name"] = serviceName
      query["service.type"] = setting.HelmChartDeployType   // "helm_chart"
  ```

### P0-6 「环境版本与快照」抽屉：接内部 cron 接口 + 回滚用错 revision 语义

- 前端：`frontend/src/pages/Environments/EnvRevisionDrawer.tsx`
  - `:83-86` 同时请求 `getProductsRevision` 与 `getProductsRevisionSnaps`；
  - `:113-120` 查看 YAML 硬编码 `isHelmChart=false`；
  - `:147-155` 回滚以 `SvcRevision.current_revision` 作为目标 revision。
- 后端：
  - `environment/handler/revision.go:57` `ListProductsRevision` **忽略 production**，恒传 false；
  - `revision.go:61-67` `ListProductsRevisionSnaps` 无鉴权、仅按 `deployType` 返回**全项目**环境快照（注释明示 “called from cron service”）；

- 修复：移除 `productsnaps` 接线（或后端新增按项目/环境鉴权的快照接口）；该抽屉回归“模板可更新性检查”，删除回滚动作；环境版本回滚统一走 `EnvServiceHistoryDrawer` 的 `/version/:serviceName` 链路；后端 `ListProductsRevision` 读取并透传 `production`。

## 五、准确契约与后端真实 API 路径

### 5.1 环境（Environments）

| 能力 | 真实路径 | 关键参数/响应 |
|---|---|---|
| 环境列表 | `GET /api/aslan/environment/environments` | `projectName`、`production`（默认 false，决定集合与权限：`Env.View` vs `ProductionEnv.View`）、`envType` |
| 环境详情 | `GET /api/aslan/environment/environments/:name` | `projectName`、`production`；`ProductResp.is_prod`（`environment_define.go:102`） |
| 创建环境 | `POST /api/aslan/environment/environments` | `type`、`projectName`、`scene`、**`production`（query，鉴权依据）**；body `CreateSingleProductArg[]`，含 `production`（落库依据，`environment_creation.go:334`） |
| 删除环境 | `DELETE /api/aslan/environment/environments/:name` | `projectName`、`is_delete`、`production` |
| 休眠/唤醒 | `POST /api/aslan/environment/environments/:name/sleep` | `projectName`、`action=enable|disable`、`production` |
| 休眠 Cron | `GET/PUT .../:name/sleep/cron` | `projectName`、`production`；`{sleep_cron_enable, sleep_cron, awake_cron_enable, awake_cron}`（`environment/service/environment.go:4717-4722`） |
| 环境服务版本列表 | `GET .../:name/version/:serviceName` | `projectName`、`isHelmChart`、`production`、`deployType`(官方传入) |
| 环境服务版本 YAML | `GET .../:name/version/:serviceName/revision/:revision` | 同上 |
| 环境服务版本 Diff | `GET .../:name/version/:serviceName/diff` | `revisionA`、`revisionB`、`isHelmChart`、`production` |
| 回滚预检 | `GET .../:name/version/:serviceName/rollback/check` | `revision`、`isHelmChart`、`production`、可选 `workflowName` |
| 执行回滚 | `POST .../:name/version/:serviceName/rollback` | query：`revision`、`isHelmChart`、`production`、`overrideResource`；body：`{detail}` |
| 产品 Revision | `GET /api/aslan/environment/revision/products` | `projectName`、`envName`、`production`（**后端当前忽略 production**） |
| 产品快照(内部) | `GET /api/aslan/environment/revision/productsnaps` | 仅 `deployType`；全局、无鉴权（cron 内部接口） |
| 环境配置历史 | `GET /api/aslan/environment/envcfgs/:name/cfg/:objectName` | `projectName`、`commonEnvCfgType`、`production` |
| 环境配置回滚 | `PUT /api/aslan/environment/envcfgs/:name` | `projectName`、`rollback=true`、`production`；body `CreateUpdateCommonEnvCfgArgs` |
| Renderset | `POST /rendersets/renderchart`、`GET /rendersets/default-values|globalVariables|variables|yamlContent` | **只读配置能力，不存在版本历史/回滚接口** |

**环境服务版本数据结构**（`common/service/version.go:50-60`、`104-119`、`243-255`、`303-306`）：
```ts
interface EnvServiceVersionItem { service_name; revision; containers[]; operation; deploy_type; deploy_strategy; detail; create_time; create_by }
interface EnvServiceVersionYaml { type; yaml; variable_yaml; override_kvs; containers[]; operation; deploy_type; deploy_strategy; chart_repo; chart_name; chart_version; detail; create_time; create_by }
interface EnvServiceVersionDiff { type; create_time_a; create_time_b; create_by_a; create_by_b; yaml_a; yaml_b; variable_yaml_a; variable_yaml_b; containers_a[]; containers_b[] }
interface CheckRollbackResponse { available: boolean; unavailable_images: string[] }
```
> `isHelmChart` 语义：`true` = `helm_chart` 类型，按 `release_name`；`false` = k8s / 普通 helm，按 `service_name`。
