## 2. A 类真实缺陷清单

### P0

本轮**未发现**与第 02 轮审批门控同级的「功能完全不可用」P0。  
（删除/睡眠/终端主路径可走通。）

### P1

#### R3-A1 · 环境回收策略 `envRecycle` 完全未接线（A · P1）

- **L3**：`router.go:149` `PUT /environments/:name/envRecycle`（`UpdateProductRecycleDay`）
- **前端**：全 `frontend/src` **零命中** `envRecycle`（协作模式 `recycle_day` 属另一域，不替代环境回收策略）
- **影响**：无法在新前端配置环境资源自动回收天数
- **建议**：环境「更多操作」增加回收天数 Modal → `PUT .../envRecycle?projectName=&production=`，body 对齐后端结构；二次确认可选

#### R3-A2 · 通用环境配置 Sync 未提供 UI（A · P1）

- **L3**：`router.go:51` `PUT /envcfgs/:name/:type/:objectName/sync`（`SyncEnvResource`）
- **现状**：`EnvConfigDrawer` 支持列表/创建/编辑/删除与 `EnvConfigHistoryModal` 回滚；`auto_sync===true` 时仅禁用编辑，**无「同步到集群」按钮**
- **建议**：对可同步对象增加 Sync 操作，封装 `environmentApi.syncEnvCfg(...)` 并 `feedback.message` 反馈

#### R3-A3 · Helm Renderset / Values 写路径缺失（A · P1）

| L3 | 前端现状 |
| --- | --- |
| `PUT /:name/helm/default-values` | `HelmRendersetDrawer` **仅 GET** `rendersets/default-values`，无保存 |
| `PUT /:name/helm/releases/:svc/values-source` | `HelmReleasesDrawer` 仅展示 Diff，**无更新 values-source** |
| `POST /:name/estimated-values` | **未接线** |
| `POST /:name/estimated-renderchart` | **未接线** |

- **影响**：Helm 环境只能看不能改基准 Values / 来源；创建或变更前缺少预估渲染
- **建议**：Renderset 抽屉增加「保存默认 Values」；Release 行操作增加 Values Source 编辑；向导/变更流接入 estimated-* 预览

#### R3-A4 · 副本伸缩硬编码 Deployment + 服务名启发式（A · P1）

- **位置**：`Environments/index.tsx:607-613`
  ```ts
  .../scaleNew?projectName=...&type=Deployment&name=${targetService}&number=${replicas}
  ```
  `targetService` 由 Pod 名正则剥离生成，易误匹配
- **L3**：`POST /:name/services/:serviceName/scaleNew` 支持按 workload `type`/`name` 伸缩
- **建议**：从工作负载列表/选中行传入真实 `type`+`name`；UI 选择 Deployment/StatefulSet 等；失败提示保留

#### R3-A5 · 服务重启未走 `restartNew`（A · P1/P2 边界）

- **位置**：`ServiceDetail.tsx:315-317` → `POST .../services/:serviceName/restart`
- **L3**：同时存在 `restart`（`RestartService`）与 `restartNew`（`RestartWorkload`，:185）
- **影响**：旧接口可用，但与官方「按工作负载重启」能力不对齐，复杂工作负载场景可能不足
- **建议**：对齐 EE 行为，优先 `restartNew` 并传 workload type/name；或双入口

### P2

#### R3-A6 · Pod 终端无心跳 / 无自动重连（A · P2）

- **位置**：`PodTerminal.tsx` — `heartbeat` 仅在类型联合中；`handleReconnect` 靠手动按钮抬升 `reconnectKey`
- **已具备**：`/api/podexec/` URL、`resize` 消息、`FitAddon`、断开状态文案、**文件下载**（:353+）
- **建议**：定时 `heartbeat` + 非主动关闭时指数退避自动重连（与全量报告 P2-1 一致）

#### R3-A7 · API 死代码（A · P2）

| 方法 | 说明 |
| --- | --- |
| `checkEphemeralContainers` | 调试容器前置检查未调用 |
| `getYamlContent` | `rendersets/yamlContent` 未接线 |

#### R3-A8 · 附属加载错误通道偏弱（A · P2）

- `index.tsx` 多处 `catch`（:315/:403/:431/:499/:560 等）部分仅清空状态；列表主路径（:356-359）已有 `message.error`
- `getServiceVariables`（`environment.ts:311`）catch 后走 POST 兜底——属兼容策略，**非**吞空，但双重失败时需确保调用方提示

#### R3-A9 · SAE 应用级运维 API 覆盖不全（A · P2，部分 B）

- 变更单 Drawer + list/abort/rollback **已有**（inventory「缺失」部分陈旧 → C）
- L3 另有 SAE rescale/restart/instance/log/pipeline 等；前端 Wizard/列表多为创建入口，**应用级运维深度不足**
- License 门控场景归 B
