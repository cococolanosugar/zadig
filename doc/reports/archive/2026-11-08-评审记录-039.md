## 1. 缺陷复核与修复确证

基于 REA 逆向导出的全景审计结论，本轮主控 Antigravity 编制实现规范并分发至 ZCode Agent，全量完成了第二梯队 4 大核心领域的契约闭环：

1. **【FULL-A-08 ~ 10 确证并修复】主机私钥连通性校验、批量导入与标签契约闭环**：
   - 文件：`frontend/src/api/settings.ts`、`frontend/src/pages/Settings/VMs/index.tsx`
   - 问题：此前新增主机仅有表单保存，缺少保存前的 SSH/凭据预检；缺少多台主机批量导入能力；标签列表仅走 `vm/labels` 未走官方 REA 契约 `privateKey/labels`。
   - 修复：
     1. `settings.ts` 补齐 `validatePrivateKey` (`POST /api/aslan/system/privateKey/validate`)、`batchCreatePrivateKeys` (`POST /api/aslan/system/privateKey/batch`) 与 `getPrivateKeyLabels` (`GET /api/aslan/system/privateKey/labels`)；
     2. `VMs/index.tsx` 创建主机弹窗新增「测试连接」按钮，在保存前主动校验连通性并反馈真实状态；
     3. 顶部操作栏新增「批量导入」按钮与 JSON 导入弹窗，支持批量录入并自动应用 `option: 'skip'` 策略；
     4. 标签筛选数据源优先走 `getPrivateKeyLabels()`，失败回退。

2. **【FULL-A-01 确证并修复】数据资产目录应用批量导入接入**：
   - 文件：`frontend/src/api/application.ts`、`frontend/src/pages/Directory/index.tsx`
   - 问题：数据资产目录仅支持逐条创建业务应用，官方 REA 契约中的批量导入端点闲置。
   - 修复：
     1. `application.ts` 补齐 `bulkCreateApplications` (`POST /api/aslan/application/applications/bulk`)；
     2. `Directory/index.tsx` 顶部操作栏新增「批量导入」按钮与模态框，内置标准 JSON 示例模板，提交前严格校验记录必填项，批量导入成功后实时刷新列表。

3. **【FULL-A-13 确证并修复】系统工具链安装包删除写路径闭环**：
   - 文件：`frontend/src/pages/Settings/Config/index.tsx`
   - 问题：系统配置应用设置（apps Tab）软件包预置列表仅有表格展示，缺少「操作」列，无法删除过时或废弃的工具链软件包。
   - 修复：在软件包表格末尾增加「操作」列，挂载带有二次确认的 `<Popconfirm>` 删除按钮，点击后调用 `PUT /api/aslan/system/install/delete`（请求体为 `{ name, version }`），删除完成后刷新列表并反馈操作结果。

4. **【FULL-A-14 确证并修复】用户中心系统用户总数统计契约接入**：
   - 文件：`frontend/src/api/auth.ts`、`frontend/src/pages/Settings/Users/index.tsx`
   - 问题：用户账号管理缺少系统全局层面的官方用户统计契约。
   - 修复：
     1. `auth.ts` 补齐 `getUserCount` (`GET /api/v1/users/count`)；
     2. `Users/index.tsx` 在页面加载时拉取系统统计指标，并在表头动态展示「系统用户总数：{count}」标签，接口异常时优雅静默降级，不阻断表格核心展示。
