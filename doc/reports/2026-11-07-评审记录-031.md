## 1. 核心修复清单

### 1.1 彻底消除 Profile API Token 硬编码与假 fallback 伪造 (P0)
- 移除 `Profile/index.tsx` 中 `useState` 初始化硬编码占位符 `'zadig_mcp_sec_live_token'`，无真实 token 时显示为空；
- 移除重新生成时 `res?.token || \`zadig_token_\${Date.now()}\`` 的假 fallback 逻辑；
- 只有在后端真实返回 `res.token` 时才更新本地状态并提示成功，否则透出错误告警，防止客户端因假令牌导致鉴权静默失败。

### 1.2 修复系统设置角色 Tab 无 `namespace` 报错缺陷 (P0)
- 后端 `GET /api/v1/policy/roles` 强制校验 `namespace` 参数，系统设置的角色列表属于系统预设角色与模板；
- 在 `settings.ts` 中将 `getRoles()` 对齐后端 `GET /api/v1/policy/role-templates`（ListRoleTemplates），消除 400 报错与假空态；
- `Users/index.tsx` 第三 Tab 改造为「系统角色与模板」，展示模板名称、说明、系统内置/自定义模板 Tag，并接入「查看权限详情」Modal，真实展示 `resource → verbs` 权限规则。

### 1.3 封装管理端「重置密码」与「重置 MFA」并在 Users 表格接线 (P1)
- 在 `settings.ts` 封装 `resetUserPassword(uid, password)` (`PUT /api/v1/users/:uid/password`) 与 `resetUserMFA(uid)` (`POST /api/v1/users/:uid/mfa/disable`)；
- 在 `Users/index.tsx` 操作列增加「重置密码」ModalForm，支持管理员直接重置用户登录密码（含密码一致性校验与复杂度规则）；
- 增加「重置 MFA」危险操作 Popconfirm 弹窗，支持一键重置目标用户的二次认证绑定。

### 1.4 全量吞错治理与创建用户说明强化 (P1)
- `Users/index.tsx`：治理 `handleDeleteUser` 与 `handleCreateUser` 的静默吞错，失败时统一透出 `feedback.message.error`；并在创建用户表单中增加详细说明，阐明系统角色与项目 RBAC 授权逻辑；
- `GroupMembersDrawer.tsx`：移除 `loadData` 静默吞错；移除在详情未返回 `uids` 时将全量用户伪装为组成员的 Fallback；
- `Projects/RBAC.tsx`：治理 `handleAddBinding` 与 `handleCreateRole` 的静默 `catch { return false; }`，操作失败时透出服务端真实错误信息。
