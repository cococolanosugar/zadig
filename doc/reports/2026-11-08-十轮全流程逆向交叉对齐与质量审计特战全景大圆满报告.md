## 二、架构攻坚重点战果剖析

### 1. 彻底斩断假数据与静态兜底
在测试中心、代码扫描、发布计划与效能大屏中，全面排查并清理了早前遗留的写死 mock 常量（如 `coverage ?? 85` 等），全面对接后端真实数据契约。若后端接口返回空或异常，界面遵循 Ant Design 6 规范给出明确的 `Empty` 或 `Alert` 提示，坚决捍卫真理源的纯正性。

### 2. 攻克微服务协议级隐秘陷阱
- **加密信封守则**：全栈通信严格执行 RSA/AES-128-CFB 混合加密流水线；
- **状态参数类型对齐**：操作审计日志中的 `status` 强制整数传递，根除 400 校验异常；
- **复杂查询参数补全**：效能洞察接口强制携带 `type: 'both'` 与动态时间窗口，彻底消灭 500 崩溃；
- **列表与详情权责分离**：模板中心全面转向全异步详情按需拉取，彻底解决列表不返 content 造成的覆写危险；
- **数组级请求体严谨构造**：Chart 模板变量配置严格构造 `[{ key, value }]` 数组，与 Gin 引擎严格匹配。

### 3. Ant Design 6 与 ProComponents 3 规范极致遵循
- 全局杜绝 `Card bordered`、`valueStyle`、`bodyStyle`、`headStyle` 等已废弃属性；
- 全局杜绝静态 `message.*` / `notification.*` / `Modal.*`，根容器挂载 `ConfigProvider + App`，统一通过 `feedback.*` / `App.useApp()` 消费；
- 每次改动执行 `antd lint ./frontend/src`，连续 10 轮保持 **0 错误、0 警告、0 废弃项**！

### 4. 严苛的双门禁验收与工程规范
- **第一门禁**：`antd lint ./frontend/src`（129 个 TypeScript / TSX 文件全部 clean）；
- **第二门禁**：`pnpm --dir frontend run build`（生产打包 0 错误、0 类型断言失败）；
- **版本控制铁律**：零 push 行为、全本地原子 commit，所有报告规范化落盘。
