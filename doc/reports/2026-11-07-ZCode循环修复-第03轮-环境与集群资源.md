## 逐项修复明细

### R3-A1（P1）环境回收策略 envRecycle 完整接线
- `api/environment.ts` 新增 `updateProductRecycleDay(projectName, envName, recycleDay)`：`PUT /environments/:name/envRecycle?projectName=&recycleDay=`（router.go:149 `UpdateProductRecycleDay`）；
- `pages/Environments/index.tsx`：
  - 新增 `recycleModalOpen/recycleDay(默认 7)/recycleSaving` 状态；
  - 环境操作 Dropdown 新增「环境回收策略」项（`HistoryOutlined` 图标，`disabled: !currentEnv`，打开时以 `env?.recycle_day ?? 7` 预填 —— `EnvironmentItem` 本地与 API 层接口均已补 `recycle_day?: number` 字段，对齐 `models.Product.RecycleDay`）；
  - 新增 Modal：`InputNumber min={0} max={365}`，附"输入 0 表示永不自动回收"提示；保存调 `updateProductRecycleDay`，成功区分提示"已更新为 N 天 / 已设置为永不自动回收"并 `loadEnvironments()` 刷新。

### R3-A2（P1）通用环境配置 Sync 操作闭环
- `api/environment.ts` 新增 `syncEnvResource(projectName, envName, type, objectName, production?)`：`PUT /envcfgs/:name/:type/:objectName/sync`（router.go:51 `SyncEnvResource`）；
- `pages/Environments/EnvConfigDrawer.tsx`：ConfigMap / Secret / Ingress / PVC 四个操作列均在「历史」之后新增「同步」按钮（`Tooltip title="同步到集群"` + `SyncOutlined`，加载态 spin 按对象粒度隔离），点击调 `syncEnvResource`（type 经 `TAB_TYPE_MAP` 映射为 `ConfigMap/Secret/Ingress/PVC`），成功 `feedback.message.success` 并 `loadResources()` 刷新，失败透出后端 message。

### R3-A3（P1）Helm 默认变量 default-values 保存更新
- `api/environment.ts` 新增 `updateHelmProductDefaultValues(projectName, envName, defaultValues, production?)`：`PUT /environments/:name/helm/default-values`（router.go:154 `UpdateHelmProductDefaultValues`，body `{defaultValues}`）；
- `pages/Environments/HelmRendersetDrawer.tsx`：
  - default-values Tab 的 MonacoEditor 去除只读：`options={{ readOnly: false, minimap: { enabled: false } }}` 并接 `onChange` 写回 `defaultValuesYaml`；
  - Card extra 新增「保存配置」按钮（`type="primary" size="small" icon={<SaveOutlined />} loading={savingDefaultValues}`），调用封装接口，成功提示"环境默认配置已保存，后续部署/同步将以此为基准 Values"，失败透出后端 message。

### R3-A4（P1）调整工作负载副本数 (scaleNew) 泛化与规范化
- `api/environment.ts` 新增 `scaleNewService(projectName, envName, serviceName, workloadType, workloadName, replicas)`：`POST .../services/:serviceName/scaleNew?type=&name=&number=`（router.go:186 `ScaleNewService`）；
- `pages/Environments/index.tsx`：
  - 新增 `scaleWorkloadType`（默认 'Deployment'）与 `scaleServiceName` 状态；
  - 弹窗重做：新增工作负载类型 Select（Deployment/StatefulSet）与服务名 Input（打开时以首个 Pod 名推导**预填**，用户可改 —— 原 `pods[0].name` 正则剥离不再是静默硬编码来源）；
  - `handleScaleReplicas` 改调 `environmentApi.scaleNewService`，空服务名前端拦截提示，错误透出后端 message，成功刷新 Pod 列表。
